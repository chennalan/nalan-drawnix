# Drawnix cloud autosave (test-first)

This directory contains the first backend implementation draft. It is not deployed and is not wired into the Drawnix UI yet.

## Components

- `schema.sql` / `migrations/0001_documents.sql`: D1 metadata schema. Apply only to a dedicated Drawnix database.
- `worker/src/index.ts`: API for list/create/read/update/delete documents. It validates a signed Cloudflare Access JWT, scopes all metadata queries to the JWT subject, limits payloads to 2 MiB, and uses optimistic revision checks.
- `worker/wrangler.toml`: configuration template with placeholders; it cannot deploy until the dedicated resources and Access values are set.

## Required configuration

1. Enable R2 in the intended Cloudflare account and verify the private bucket inventory.
2. Create a dedicated test D1 database named `nalan-drawnix-test` and a dedicated private R2 bucket named `nalan-drawnix-documents-test`; do not reuse `nalan-work`, `nalan-mindmap`, or `nalan-backup` without a separate review.
3. Configure Cloudflare Access for the API hostname and restrict access to the intended user(s). Copy the Access team domain and application audience into Worker variables.
4. Set `ALLOWED_ORIGIN` to the exact Drawnix preview origin during testing.
5. Apply the migration, then deploy only the test API.
6. Test login, anonymous rejection, cross-user isolation, save/reopen, concurrent revision conflict, oversized payload rejection, offline recovery, and delete behavior.
7. Integrate the frontend only after API tests pass. Keep localforage writes as the immediate recovery layer and show explicit cloud-save status.

## Security notes

- The API trusts only a cryptographically verified Access JWT, not browser-supplied user IDs or email headers.
- D1 ownership checks are included in every document-specific query.
- R2 object keys are generated by the API and the bucket must remain private.
- Document JSON is not served from a public R2 domain.
- Production deployment and DNS changes are intentionally out of scope until test verification is complete.
